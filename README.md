# Zeno's Private Hair Atelier

Neue Website für https://zenoshairatelier.ch – React + Vite, Tailwind CSS v4,
Framer Motion, lucide-react und shadcn/ui-Komponenten (Button, Dialog) als PWA.

```bash
npm install
npm run dev     # Entwicklung
npm run build   # Build nach dist/
```

Buchungslink und Leistungen: `src/content.js`.
